# M-05: Realtime wiring (buildMonadAdapter/Executor + routing)

Status: done
Delegation: high
Depends on: M-03, M-04
Blocks: M-07, M-08

## Goal

Wire the Monad DEX adapter and executor into `backend/src/realtime/realtime.service.ts`
behind `cfg.monad.enabled`: add `buildMonadAdapter()` and `buildMonadExecutor()`
mirroring the Injective builders, push `'monad_dex'` into `allowedDexes`, and
route `chain === "monad"` quotes in `RealTimeAgentCore` to the Monad executor so a
prepared trade produces a `monadExecutionPlan` on the `TradeExecutionPlan`.

## Non-goals

- Do not generalize the arb strategy (M-06).
- Do not modify the frontend (M-07).
- Do not add new REST endpoints; reuse existing `/realtime/trade/prepare` +
  `/realtime/trade/confirm` (add an execute path analogous to
  `/realtime/trade/injective-execute` only if needed — prefer reusing).
- Do not change Solana or Injective routing.

## Constraints (red lines)

- All Monad wiring is gated behind `cfg.monad.enabled` (default false). When
  false, `realtime.service.ts` constructs zero Monad objects and `allowedDexes`
  is unchanged — behavior identical to today.
- `RealTimeAgentCore` route selection: a winning quote with `chain === "monad"`
  builds a `MonadExecutionPlan` (not an `InjectiveExecutionPlan` and not a
  Solana unsigned tx). The plan is attached as `monadExecutionPlan` on the
  returned `TradeExecutionPlan`.
- The executor is selected by chain: `monad` → `monadExecutor`, `injective` →
  `injectiveExecutor`, `solana` → existing Jupiter/mock path.
- `monadExecutor` is `MockMonadTradeExecutor` when `MONAD_PRIVATE_KEY` empty,
  `MonadViemExecutor` otherwise — same keyless-by-default rule as Injective.
- No real signing in tests; mock the executor.
- No secrets in logs.
- LLM/JEV must not influence route selection — routing stays deterministic
  (nBBO best price within risk caps).
