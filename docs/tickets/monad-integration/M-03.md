# M-03: Monad DEX adapter (0x/1inch API + mock fallback)

Status: done
Delegation: medium
Depends on: M-01, M-02
Blocks: M-05

## Goal

Create `backend/src/dex/monad-dex-adapter.ts` implementing `DexAdapter`, which
fetches a swap quote from the 0x (or 1inch) Swap API for a Monad pair and
returns a `DexQuote` tagged `chain: "monad"`, `source: "monad_dex"`. Include a
deterministic mock fallback (same shape as `InjectiveHelixAdapter.mockQuote`)
used when the API is unconfigured/unreachable, tracking the Pyth oracle mid +
a configurable Monad premium.

## Non-goals

- Do not wire the adapter into `realtime.service.ts` (M-05).
- Do not implement the executor / signing (M-04).
- Do not support Uniswap V3 Quoter direct reads in this ticket (aggregator API
  only; Quoter path is a documented future fallback).
- Do not execute real swaps; quote-only (price + outAmount + priceImpact).

## Constraints (red lines)

- Adapter implements the existing `DexAdapter` interface (`source`, `quote`).
- `source` is `"monad_dex" as const`.
- All returned `DexQuote` have `chain: "monad"`.
- No real API calls in tests — mock `fetch` / use a fixture response.
- `MONAD_DEX_MODE` config selects `0x | 1inch | mock`; when the selected
  mode's API key is empty OR the fetch fails, fall back to `mockQuote`
  (logged at `warn` level, same as Helix).
- No float for `outAmount`/`inAmount` — use `bigint` via `outputAmountFromPrice`.
- No secrets in logs; the 0x/1inch API key is never printed.
- `fetchTimeoutMs` default 2500; abort on timeout.
- Adapter is only constructed when `cfg.monad.enabled` (M-05 gates this).
