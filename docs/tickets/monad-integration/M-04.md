# M-04: Monad executor (viem signer + mock)

Status: done
Delegation: medium
Depends on: M-01
Blocks: M-05

## Goal

Create `backend/src/transactions/monad-executor.ts` with a `MonadTradeExecutor`
interface, a `MonadViemExecutor` (builds + signs an EVM swap tx via `viem` using
`MONAD_PRIVATE_KEY` and broadcasts to `MONAD_RPC_URL`), and a
`MockMonadTradeExecutor` (returns a simulated tx hash when no key is set).
Mirrors `InjectiveTradeExecutor` / `MockInjectiveTradeExecutor`.

## Non-goals

- Do not wire the executor into `realtime.service.ts` (M-05).
- Do not implement the DEX adapter (M-03).
- Do not support the community `monad-mcp` server in this ticket (documented
  future option only).
- Do not execute real transactions in tests.

## Constraints (red lines)

- `MonadTradeExecutor` interface: `isAvailable(): Promise<boolean>` +
  `executeTrade(request: MonadTradeRequest): Promise<MonadTradeResult>`.
- `MonadTradeRequest` carries a `MonadExecutionPlan` + `TradeIntent` + optional
  `options` (same shape as `InjectiveTradeRequest`).
- `MonadTradeResult`: `txHash?`, `status: "submitted"|"confirmed"|"failed"|"simulated"`,
  `message`, `raw?` — same fields as `InjectiveTradeResult`.
- `MonadViemExecutor` uses `viem` `createWalletClient` + `parseAccount` with a
  `localAccount` from `privateKeyToAccount`. No child process (unlike Injective MCP).
- When `MONAD_PRIVATE_KEY` is empty, `realtime.service.ts` (M-05) selects
  `MockMonadTradeExecutor`; this ticket just provides both classes.
- No real signing in tests — mock the wallet client / never call `sendTransaction`.
- No secrets in logs; the private key is never printed.
- `isAvailable()` for `MonadViemExecutor` returns false if the key is empty or
  viem fails to construct the account.

## Tests

- `backend/src/transactions/monad-executor.spec.ts` (new):
  - `MockMonadTradeExecutor.isAvailable()` → true; `executeTrade` returns
    `status: "simulated"` + a `mock_mon_...` tx hash.
  - `MonadViemExecutor.isAvailable()` → false when key empty; true when a
    throwaway test key is provided (do not broadcast).
  - `MonadViemExecutor.executeTrade` with a mocked `sendTransaction` → returns
    `status: "submitted"` + the mocked tx hash; never hits the network.
  - On a simulated broadcast failure → returns `status: "failed"` + message,
    does not throw (matches Injective executor behavior).
