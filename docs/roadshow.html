02

项目简介 & 产品与解决方案

将原本只服务 Solana 的量化 Agent 升级为 链无关(chain-agnostic) 的跨链交易大脑:在 Solana DEX 与 Injective Helix 之间聚合单一最优报价(nBBO),扫描跨链价差,并对外暴露标准化 MCP 接口供其他链上 Agent 调用。

核心能力

  • 跨链 nBBO 聚合:fan-out 到 Jupiter/Raydium/Orca + Injective Helix,产出单一最优买卖盘
  • 跨链套利扫描:BTC/ETH 等共有资产中间价 − 桥成本 = 净 edge(bps)
  • 自然语言量化助手:LLM 通过 LangChain tools 调用 nBBO / 套利 / 身份查询,生成跨链计划
  • Injective 执行层:命中 Injective 路由时经官方 MCP server 签名广播

双向 Agent 身份

  • 消费方:调用 Injective 官方 MCP server 完成下单
  • 提供方:在 Injective Agent Registry 注册 ERC-8004 身份卡,声明 services
  • 对外暴露 MCP server(Streamable HTTP /mcp),4 个标准工具
  • 任何 Injective Agent 都可按卡片发现并调用我们

痛点与解决方案

  • ✕
    链间流动性割裂 — Solana 与 Injective 各自盘口无法互通,同一资产存在持续价差却难以捕获。→ 跨链 nBBO 聚合 + 套利扫描,自动定位最优买卖方向。
  • ✕
    Agent 之间无法互调 — 链上 Agent 各自为政,缺乏标准身份与服务发现机制。→ ERC-8004 身份卡 + 对外 MCP server,任何 Injective Agent 可发现并调用我们。
  • ✕
    量化门槛高 — 普通用户难以编写跨链套利逻辑。→ 自然语言指令经 LangChain tools 转化为可执行跨链计划,带 tool-call 留痕可审计。
  • ✕
    执行风险难控 — 滑点、预言机偏差、报价时效难以统一约束。→ 风控引擎对六维度上限硬校验,超限路由直接拒绝。
